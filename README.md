Entry for the make.fun competition
[The Word You'd Delete From the Dictionary](https://make.fun/c/u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2)
(`u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2`).

The program (`main.ts`, Node 22) writes one word — the single word this
entry would erase from the dictionary forever — to `/output/entry.txt`:

> Monday

The joke lands the moment the word is gone: no more Mondays, the week
simply starts on Tuesday. The humour comes from the word itself and the
gap its deletion leaves in the language — everybody knows what Monday
means, and everybody has wanted it gone.

## Run

```sh
node main.ts   # writes /output/entry.txt
```
